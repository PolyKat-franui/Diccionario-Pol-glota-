# Diccionario-Pol-glota-
App y página web para aprender el vocabulario y las frases cotidianas de varios idiomas a la vez, con acceso rápido a diccionario de cada idioma. Método base: recuerdo activo y repetición espaciada (SRS), seisiones rápidas, repetir frases cotidianas y responder, para perder el miedo a hablar y mejorar la pronunciación. Diccionario de idiomas.
